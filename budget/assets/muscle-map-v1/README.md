# Static muscle map

`body-front-back.webp` is generated artwork commissioned for the Maja/Markus exercise guide on 2026-10-26. It is a 1448 × 1086 sheet: front on the left, back on the right. Each 724 × 1086 half shares its coordinates with the interactive SVG overlay in `pulse-muscle-map.js`.

Mode: image generation using the existing silver exercise mannequin as a style reference. Prompt: two full-body silver anatomical mannequins, front and back, neutral standing A-pose, abstract face, modest pelvis, subtly coral muscle groups, seamless near-black #090d13 studio environment, soft floor shadows, no text, labels, UI or equipment. Preserve a consistent scale and generous margins for interactive areas.

The delivered PNG was converted to WebP at quality 87. The page only displays a static image; accessible hit areas and buttons are real HTML/SVG. This illustration is a simplified exercise navigation aid.
