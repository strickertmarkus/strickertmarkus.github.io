Shopping list engine V7
=======================
Status: ACTIVE / SINGLE-STATE MODEL

- budget/shopping-list-engine-v7.js owns normal shopping item/category rendering and add/edit state.
- No empty placeholder items are stored in sh_lists.
- Category -> Enter saves the category and opens one item draft.
- Item draft -> Enter saves exactly one item and opens exactly one new draft.
- The same path is used for item 1, item 2, item 3, etc.
- Existing item -> Enter saves the edit and opens a new draft after that item.
- Blur saves non-empty drafts but does not create an extra row.
- Escape cancels the active editor.
- Draft text is mirrored to JS state on every input event.
- Main item/category editing uses contenteditable to avoid iOS form-input zoom.
- (Willys)/(Maxi) suffix routing is native in V7 for normal shopping items.
- Unknown category suffixes follow Home behavior and move the cleaned item to uncategorized area.
- Yellow Shopping accents and Home-derived row geometry are retained.

Shopping rapid-interaction stability V8
=======================================
Status: ACTIVE

- budget/shopping-list-stability-v8.js is loaded BEFORE the V7 engine so its capture-phase guards are registered first.
- Late focusout events immediately following Enter are suppressed for a short transition window. This prevents Safari/iOS from closing or committing the newly-created editor because the previous DOM editor lost focus during re-render.
- Repeated/held Enter events are ignored during the transition window so one physical action cannot create multiple state transitions.
- Delete actions have a short 115 ms acceptance guard. Deliberate rapid deletion remains possible, but accidental cascading deletion caused by rows shifting under the same finger gesture is prevented.
- Local sh_lists firebase-sync echoes are ignored for 260 ms after an accepted local mutation; V7 has already rendered the local result, so this removes redundant DOM churn during rapid delete/add sequences.
- Checkbox local mutations use the same short local-echo guard.
