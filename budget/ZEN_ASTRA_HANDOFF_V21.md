# Zen v21 handoff — Stretch tree comparison

Temporary visual comparison control for Stretch:

- A small `Träd · Ny/Original` toggle is shown only on the Stretch home hero.
- `Ny` keeps the current v20 Stretch foreground tree/depth renderer.
- `Original` hides the v20 foreground canvas and the later Stretch-only foreground shade planes, revealing the existing v3 forest/tree renderer underneath.
- Current page layout is intentionally unchanged while toggling; this is a scenery comparison only.
- Preference is stored locally under `zen-stretch-tree-compare-v21`.
- Files: `zen-tree-compare-v21.css` and `zen-tree-compare-v21.js`.

This comparison control is temporary and can be removed once a preferred tree version is chosen.
