Visa formler (Överföringar) Husutgifter = Totalt hus (ränta + drift + amortering + renovering) + Huskonto-utgifter
Netto total = Markus netto + Maja netto
Maja % = Maja netto / Netto total   Markus % = Markus netto / Netto total
Huskonto Maja = INT(Husutgifter × Maja%)   ICA Maja = INT(ICA-kort × Maja%)
Huskonto Markus = INT(Husutgifter × Markus%)   ICA Markus = INT(ICA-kort × Markus%)
Total huskonto = Huskonto Maja + Huskonto Markus   Total ICA = ICA Maja + ICA Markus
Från januari 2027 räknas Husutgifter ut automatiskt (märkt auto) och nästa månad läggs till av sig själv, med ICA-kort och nettolöner från månaden innan. Skriv ett eget belopp i Husutgifter för att ersätta formeln, töm fältet för att gå tillbaka till den.
